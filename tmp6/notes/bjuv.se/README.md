# bjuv.se chain notes (kf = Kommunfullmäktige)

- The bjuv.se chain may receive Kommunfullmäktige protocols from other
  municipalities than Bjuv (observed: Askersunds kommun). The protocol text is
  authoritative for organization_name, organization_location and all meeting
  facts; do not "correct" the municipality to the chain target (same rule as
  documented in the ljungby.se note, the boden.se note and the
  canonicalization-worklog boden.se entry).
- Kommunfullmäktige protocol structure here: decisions are §-blocks with a
  "Beslut" section; information items (revisorerna informerar, nämndrapporter,
  mötets öppnande) are not decisions.
